# 🛠️ IT Support Knowledge Base

A structured IT Support Knowledge Base repository containing real-world L1 troubleshooting scenarios for Windows, Networking, Software Applications, and Linux environments.

This project demonstrates troubleshooting, technical documentation, SOP writing, and issue resolution skills commonly required in IT Support, Service Desk, and Help Desk roles.

---

# 🎯 Project Objectives

✅ Document common IT support issues  
✅ Provide step-by-step troubleshooting procedures  
✅ Demonstrate technical documentation skills  
✅ Simulate real-world L1 support workflows  
✅ Build a professional GitHub portfolio project
